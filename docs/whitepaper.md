# 合芽自主公链研究网白皮书 v0.2

合芽让个人设备自愿参与模型微调，把计算正确、质量评测与奖励结算分开。首版基于Cosmos EVM/SDK/CometBFT开发独立节点`heyunad`，有独立创世、原生币与受邀验证者网络，支持Solidity及常见以太坊工具。自有新增工作集中于经济规则、确定性贡献模块、原生领取与隔离客户端。[锁定依赖](https://github.com/cosmos/evm/blob/v0.7.3/go.mod)

## 目标与证据

本轮完成标准是可复现的独立研究链和可信贡献实验。“领先50年”“最安全”“超越BTC”不作为验收或宣传结论。长期演进靠明确假设、公开失败、独立评审与持续运行证据建立。速度/功能/测试数量不能替代安全证明。

## 创世经济

20,000,000枚、18位小数、研究标记`tHEYUNA`。70%共训、20%共识安全、10%公共基金，团队固定预留0。无周期增发；标准执行/质押惩罚中的明确销毁可减少供应，后续净增发违反跨版本不变量。Gas、质押、基金和奖励共用SDK/EVM账本。

共训14m按520周整数差分，训练90%、独立复算10%；未使用留库，计划后受原单周及类别累计限额约束。共识4m含40k启动自质押与3.96m受约束补贴，1040周为研究基准，对照520/2600周。基金2m含100k明确水龙头拨款，余1.9m需3/5与7天延迟。研究币不承诺价值、固定收益或主网兑换。[经济规范](rewards.md)

## 链与可信贡献

四个等权本地节点，公众质押准入关闭。一个节点故障仍可形成法定多数；两个失联应停链，恢复后核对相同最终状态。这只覆盖所测故障，不证明抵抗任意拜占庭攻击。[共识规范](https://github.com/cometbft/cometbft/blob/main/spec/consensus/consensus.md)

正常链297011挑战72h；独立加速链297012挑战3s，仅供演练。节点不下载模型、不运行Python、不做浮点质量判断。跨链/桥和非必要原生写预编译关闭。当前仅loopback、零基础费启动；公众费率、独立节点及资源约束另设验收。[兼容矩阵](evm-compatibility.md)

必须分别验证：指定计算结果符合模板；更新通过独立保留集评测；同一成果不重复计奖。固定Qwen3-4B版本、冻结LoRA A、仅训练B，任务绑定模型/分词器、数据、模板、配置、轮次及收款人。协调器不能下发任意程序；项目/对话默认不用于共训。

三名受邀验收者、2/3报告和批次票决。任何人登记挑战，一名验收者冻结待确认批次，门槛授权恢复/取消，终态不可覆盖。签名与Merkle证明只能证明分配记录和领取规则；串谋仍是明确边界。

实验覆盖跳步、旧结果、复制、数据替换、投毒和串谋，报告接受率/误拒率/耗时/置信区间。新方案只有在预注册检测门槛内且至少降低30%验证耗时才可替代完整复算。本轮抽样未达门槛，继续使用完整复算。Tiny样例改善不等于通用模型收益。[实验](contribution-research.md)

原创碳黑/银白/青绿工作区、训练、奖励、记录与设置。三金属曲面聚芽的装置只在空闲运行；开始编程或贡献、失焦/离屏/减少动态效果时释放3D资源。未核验金额显示“—”；外部钱包独立签名，模型和训练进程没有钱包权限。

从[NIST FIPS204 ML-DSA](https://csrc.nist.gov/pubs/fips/204/final)开始密码迁移研究。当前离线四角色域分离与混合迁移状态模型尚未接入链。必须分别迁移账户、共识、网络身份和更新签名，跟踪标准勘误；更换一种算法不能声称整链抗量子。[实验范围](crypto-migration.md)
