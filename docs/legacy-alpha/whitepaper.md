# 合芽网络技术白皮书 v0.1

合芽把个人设备上的自愿协作微调、可核查贡献和受约束的奖励连接起来。首期目标是证明少量受邀设备能完成一致的模型更新和可追溯结算，再讨论规模化。手机、开放无许可训练以及通用计算证明均为后续研究。

## 产品与协作方式

用户先获得一个本地编程工作区，可阅读项目、在隔离副本中修改代码并运行测试。共同训练默认关闭，由用户设置运行时段、内存和上传限额。编程项目和对话不会自动转为训练资料。公开任务须标明数据来源、许可证、用途和哈希；不接受来源不明或含个人敏感资料的任务。

任务版本、模型和分词器版本、共享适配器、训练模板和结果均有身份记录。验收使用格式检查、更新幅度检查、抽样复算、重复挑战和独立保留集；每项只降低其覆盖的攻击风险。准入、协调和验证仍有信任假设，不能把多账户等同于多人独立控制。

## 奖励和公共治理

总供应量为 2,000 万枚，18 位小数。90% 奖励有效训练和验证工作，10% 进入公开公共基金，没有团队固定份额。部署时一次性创建全部供应量，领取只是转账；代币无增发、税、重基准、黑名单或任意扣款功能。

首期预算按 520 个周周期、整数差分安排。默认训练90%、验证10%，不按账户数、在线时长、持币或自报利用率发钱。未用预算留在库中，计划期后以既定单周上限继续分配，直至耗尽。公开清单、验证签名、挑战期、最终确认和链上领取分别记录。无价值担保、无固定收益、无测试币兑换承诺。

公共基金受多签和七天延迟约束，提案公开用途、收款方和依据；代币余额并不意味着已有支付审计费用的现金。主网之前需要真正独立的3/5管理者和恢复流程。

## 安全与经济边界

共训验收和底层共识是两个问题。借用以太坊结算不会使训练真实；更多功能也不会证明比比特币更安全。我们公开实现复杂度、签名权限、服务可用性、串谋和投毒风险，分阶段记录测试证据。主网必须通过两家独立机构审计及修复复审、公开赏金和真实设备攻击演练。形式化证明只覆盖明确规格及假设。

首期不开发自有公链、跨链桥、借贷、交易撮合或所谓抗量子币；不销售未经验证的训练收益。服务预算上限为每月人民币1,000元，研发、设备、审计、法律和部署gas另列。预算是工程约束，不是已经发生的采购。

实现细节以 [架构](architecture.md)、[共训](federation.md)、[合约规则](rewards.md) 和 [验证记录](verification.md) 为准；本白皮书不构成这些门槛已完成的证据。
