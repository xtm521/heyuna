# Security policy

This is experimental invited-testnet software. Do not entrust mainnet funds or production credentials to this version. No audit or “world safest” claim is made.

Report vulnerabilities using this repository's **Security → Report a vulnerability** when private reporting is enabled. If unavailable, contact the repository owner through an existing private GitHub channel to arrange confidential disclosure; do not publish exploit secrets, seed phrases or live credentials in issues. Do not assume an invented email is monitored.

Include affected commit, environment, minimal reproduction, impact, and a suggested mitigation. Use local chains/test fixtures and accounts you control; do not attack unrelated users or services. Maintainers will acknowledge as capacity permits; this alpha does not promise a 24/7 response or a funded bounty before one is announced.

Critical or high findings block deployment. Publish fixes, regression tests and the affected release range after coordinated disclosure. The emergency reward pause cannot freeze ordinary transfers or increase supply. See docs/threat-model.md for trust assumptions and residual risks.
