# 安全预算敏感性模拟

这是确定性算术模型，不是收入预测。研究币没有已确认兑换价值，基准价值按 0 元计；非零值仅用于展示假设变化。4 个等权验证者的 40,000 枚初始质押不算运营收入。3,960,000 枚补贴从创世预留支出，不增发。

满参与、每周有最终确认才达到以上理想支出；漏签、整周停机和整数舍入留下的余额不会自动补发。1040 周之后，代码不再从这份预留支付补贴；2600 周不产生额外预算。

以下是假设每个节点每月支出 250 元、平均每笔手续费 0.001 HEYUNA 时，需要的持续平均交易量。假设手续费一半为基础费、一半为优先费；基础费扣 2% 社区税，优先费直接给实际提议者，网络合计按 99% 计；运行支出未包括专业运维、审计和冗余。

完整 JSON 包含 432 个成本、假设兑换值、手续费和交易量组合。所有非零兑换值均是假设，不表示研究币可交易或保证未来价值。

当前本地网络关闭动态基础费并允许零费初始化；这不能证明公开网络的抗垃圾交易能力或费用可持续性。应用现已将退款后的最终计费 gas 对应优先费支付给实际提议者，基础费余款保留于 fee_collector 并由 distribution 分配；不销毁基础费。以上 50/50 费用构成仅是情景假设，当前零基础费本地网络不代表公开市场。默认 min_gas_multiplier=0.5 还会将计费 gas 下限设为 gas limit 的一半。

独立运营前需要用实际报价与负载替换所有假设，并完成非零基础费、节点恶意行为、参数变更和预算耗尽后的退出机制验证。50 年（2600 周）只是模拟时间点，不是技术领先或持续运营承诺。
