# 隐私材料草稿 · 尚非最终法律政策

核对日期：2026-10-26。本文件根据当前源码描述行为，供发行前形成正式隐私政策和 App Store 隐私答卷。**运营主体、联系人、公开政策 URL、地区要求和依赖二进制的最终隐私报告尚待确认，不能将此草稿标为法律已确认或已发布政策。**

## 当前数据流

| 数据 | 当前去向与用途 | 保留 / 删除边界 |
| --- | --- | --- |
| 助记词、派生密钥 | 在设备内创建/导入；助记词存系统 Keychain，派生和签名在 App 进程执行，不发送给 RPC、Esplora 或开发者服务 | 无云同步、无共享钥匙串。用户可在验证身份后移除此设备的钱包；离线备份由用户保管 |
| 公共地址、BTC 公共描述符 | 本地钱包文件，用于收款与查询 | 目录排除系统备份；移除钱包会清除账户和应用内交易记录，节点设置可保留。描述符可关联多个地址，不应公开 |
| 用户填写的节点地址 | 本地保存，按所选网络连接；无内置远程默认节点 | 可清空/替换节点设置。不要在 URL 路径中放敏感凭据；URL 不接受内嵌账号、密码、查询参数或片段 |
| IP、地址/脚本查询、区块与费用请求 | 用户主动查询、预览、签名核验或刷新状态时发送给所选 HTTPS RPC/Esplora；服务运营者可看到并关联这些信息 | 节点日志、留存、地区及运营者政策由实际服务决定，应用不能保证其删除或不记录 |
| 已签名交易 | 用户确认并通过系统身份验证后发送给所选节点进行广播 | 交易可进入公开点对点网络和不可由 App 删除的链上历史；广播失败/未知仍可能已被接收 |
| 本地交易哈希、金额、地址与状态 | 广播前先保存哈希以防不确定结果引发盲目重发；随后显示交易状态 | 移除此设备钱包清除应用内列表，不会撤销或删除链上交易 |
| 外观偏好 | 通过 App 自身的 UserDefaults 保存浅色/深色等界面设置，不读取其他 App 偏好 | 仅本地使用；不是地址、密钥或跨 App 识别标记 |

当前 App 没有开发者运营的账户系统、分析/广告 SDK、自动遥测上传、联系人上传或训练数据上传；不访问编程助手的项目、对话或共训记录。**默认不联网不等于联网后匿名**；节点能关联 IP 与钱包活动，区块链本身公开。

Bitcoin 使用应用自己的 HTTPS Esplora 读取适配器，接收与找零分支各最多查询 200 个地址，按 gap 20 提前停止，并设置超时、请求数和响应大小上限；这些限制减少资源消耗，不提供匿名性。扫描关联的多个地址和原始交易请求仍可能被节点识别为同一个钱包。BitcoinDevKit 在本地解析和签名，节点查询不经过其 HTTP 客户端。创世、原始交易与区块信息一致性检查不能证明节点诚实，应用不执行 SPV 或完整共识验证。

## 用户控制

- 首次启动不配置远程端点。用户选择并填写各网络 HTTPS 节点，保存地址本身不代表已经核验或连接成功。
- 可以不配置网络，离线创建/导入、备份并查看收款地址；查询余额及发送必须联网。
- 系统身份验证用于访问本地钥匙串。App 不接收生物识别模板，不把 Face ID/Touch ID 模板发送给开发者。
- 没有 App 账号，无需注册邮箱或手机号。移除此设备钱包须先验证身份；操作不撤销转账、不抹除链上记录、不替代离线助记词备份。
- 本地文件、系统钥匙串、设备备份与卸载行为不同。请勿把卸载当作已验证的安全擦除，也勿把钥匙串当作跨设备恢复服务。
- 助记词页面可能被旁观、截图或其他已获权限的软件记录；App 生命周期锁定不能证明阻止了所有屏幕采集。

## App Store 填写与隐私清单

`Config/PrivacyInfo.xcprivacy` 是当前应用代码的初始清单：不声明跟踪、跟踪域名或开发者数据收集；为 `@AppStorage("wallet.appearance")` 使用 App 自身的 UserDefaults 保存外观偏好，列出 `NSPrivacyAccessedAPICategoryUserDefaults` / `CA92.1`。此原因仅适用于 App 自身数据，不授权读取系统或其他 App 的偏好。[原因码官方说明](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype)

**这不是最终依赖审计结果**。发行时必须聚合并核查锁定的 Swift/Rust/预编译库，依据真实访问增加适用原因，不能为了通过校验填不匹配的原因码。

当前不存在由开发者自动收集钱包数据的后端，但用户选择的服务可能保留地址、IP 与交易。最终 App Privacy 答卷必须依据实际集成关系、服务控制和留存逐项判断；不能仅凭“自托管”或清单空数组就承诺“没有任何数据离开设备”。增加默认 RPC、崩溃上传、分析、推送、云备份或客服附件上传前，应先更新数据流、用户说明、清单和商店标签。

Apple 要求描述应用及其集成第三方的实际隐私行为；隐私清单不替代公开隐私政策和 App Store 问卷。[App Privacy 官方说明](https://developer.apple.com/app-store/app-privacy-details/) · [Privacy Manifest 官方文档](https://developer.apple.com/documentation/bundleresources/privacy-manifest-files)
