# Heyuna design tokens

Original carbon / graphite / silver / teal system, shared by the desktop renderer and the separate wallet portal. The CSS is imported locally; no remote font, texture or brand asset is fetched. Inter Variable is bundled by each app under its SIL Open Font License through the pinned `@fontsource-variable/inter` package. The three curved ribbons in `SproutMark` and `sproutScene` are original project artwork. No third-party affiliation or endorsement is implied.
